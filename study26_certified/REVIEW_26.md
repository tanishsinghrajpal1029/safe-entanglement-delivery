## Checked and found correct

- **Umax / levels.** Umax = 4 (ion2020, nv2, siv; Lmax 2) and 7 (ionproj; Lmax 3), from the actual candidate sets. The U-size histogram for ionproj is 80×1, 60×2, 40×3, 64×4, 96×7 links. lvl = 0.0125 / 0.00714 for corrected arms and 0.025 / 0.0167 for L arms. All three guard branches in st() (fleetmix, hedge, beta) use `s.lvl`. The campK branch from Study 25 is removed and unused.
- **base_of** maps all 15 arms correctly. Checked the guard / belief / tsplit flags: ag2t, ag2tL and ag2tR give hedge / mlp / tsplit = True; plug, plugM and cut give fleet / no guard, kind set correctly.
- **Per-user metric.** cands are ordered pairs (204 / 340 users). ustat is keyed by candidate index, counts only measured deliveries, and users_total = len(cands).
- **Lemma B / ag2t.** Changing a link's own counts at the freeze leaves its own row of (mz, sz) exactly unchanged (tested on links 0, 17, 39), so features2 uses other links only. jf = freeze - E0 = 3. The prior uses N_c[3] (epochs -1..2). The CS uses N_c[j] - N_c[3] (epochs 3..e) and is zero for e <= freeze. Deflation by phi_decl is applied to the time-split counts. The recursive st(freeze) sets ai_prior correctly; the cache shows keys [3, 6] after st(5).
- **Block R noise.** Link shift sd = rel·qbar for g = 1 (A² @ snode² with the √2 factor). E[g²] = 1. The AR start is stationary. The conditional-expression precedence on line 129 is correct. The phi_true formula is validated by simulation (E[Pearson]/phi_true = 1.00). The campaign shares gmul and the link qualities but uses an independent RNG (seed 262) for noise and Poisson counts. Per-link chi-square bounds (Rp) have 95% per-link coverage. Arm-to-phi_decl mapping: Rp is checked before R, and O uses the per-link array.
- **Block O.** se = 0.0436·sqrt(4/M). d = Delta + se·z + 1.645·se, so P(d < Delta) = 5%. m0 gives d = 0 (`tom = 0` is falsy). orc gives d = Delta. The guard uses F(lamlo) + Delta - d and the controller uses Fs + Delta. Delta_hat uses common random numbers across the two Delta values. O3 behaves as predicted: o0.044_m0 had r = 57% and users_bad 119/204.
- **Baselines.** plug and plugM use the posterior-mean point estimate with Pm and the + m margin. cut uses hold <= x/((1-RHO)R), where RHO = 0.3 is the calibration fraction and the units are the mean link-generation time. Same belief and routing, no controller, no guard. They consume the same RNG stream as the guard arms.
- **Block S.** path_nodes gives 1/1, 1/2/1 and 1/2/2/1. Start = max(link busy, q-th earliest slot). The q earliest slots are set to the end time, all of them <= start, so there is no overlap. The oracle has separate slots. `need` and `oneed` are defined whenever they are used. No epoch clamping: max_epoch was 28-29 in all S, U, R and O runs, including ion2020 q2 (111 s) and siv.
- **Seeds.** nseed and rseed depend on (block letter, hw, idx) only, so they are paired across arms and configs. Pilot networks differ through seeds[0]+seeds[2] (net RNG and fleet law) and seeds[1] (run RNG). Block R, O and campaign RNGs all include seed[2:].
- **Output columns.** All keys are set unconditionally in `run()`, in the same insertion order, with no Study 25 `camp_*` columns.
- **Analysis.** EXPECT = 36 / 252 / 24 / 27 cells, and confirmatory task count = 10848 (= 339 × 32). Pilot = 3160 tasks. The bootstrap UB is a percentile UB over networks, and dd = 0 resamples are handled. paired_diff pairs on idx within hw (one cfg per arm in U; R5 filters by cfg). U2 sign is legacy - corrected = cost. R5 sign is kgR - kg >= -3. O2 level is 10%. R2 = 64 and R3 = 32 cells. Both `tune` and `all` run end-to-end on synthP and synthA.
